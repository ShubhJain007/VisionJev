# PROBLEMS.md — known problems and proposed improvements (living list)

Keep this file current: add every newly observed problem with its evidence, update the status as fixes land, never
delete an entry (mark it `fixed` / `wontfix` with the reason). Evidence points to `results/experiments.jsonl` records,
logs or commits. Priority: **P0** blocks good runs · **P1** clear quality gain · **P2** worth doing · **P3** later.

Status values: `open` · `in progress` · `testing` · `fixed` · `wontfix`.
